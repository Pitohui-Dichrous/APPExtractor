## 配色角色

- 页面、顶栏、启动窗口与系统栏使用 `#C29E64`；卡片及弹窗使用浅金色 `#DBC398`。
- 主要按钮与操作图标使用 `#4C7543`；名称、多选、包名等文字使用中性色。
- 系统浅色和深色模式保持相同品牌配色。菜单与弹窗的高度效果保持原有金色。
- API 34 首页截图中，精确 `#C29E64` 占画面 64.65%，为面积最大的颜色；浅金色卡片占 26.70%。系统夜间模式统计相同。API 29 对应金色背景占比为 70.08%。
- 绿按钮白字对比为 5.34:1；绿色图标对卡片底色为 3.12:1，对图标小底为 4.25:1；次文字在主背景上为 4.67:1。
