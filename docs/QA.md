# APPExtractor 1.1.0 验证

发布 APK：`APPExtractor-1.1.0.apk`，1,493,696 字节。

SHA-256：`8b5a2ee6514382ba3ef36489db09aed86e443b715148f40f7ef88d815febfb4f`

- 版本 1.1.0（2），支持下限 API 26。签名与 v1.0.0 一致，可覆盖升级。
- 12 项测试全部通过：8 项导出核心测试、4 项重名策略测试。Android Lint 无错误。
- Android 10（API 29）和 Android 14（API 34）独立模拟器均已从旧版覆盖升级，启动和导出正常，无运行崩溃。
- 默认文件夹设置后直接导出；连续重名提取保留原文件并自动编号。重启后仍可免选择位置导出。
- 目录选择器打开时终止应用进程，恢复选择后仍成功保存默认文件夹；取消更换保留原设置。
- 切换「每次询问」后恢复系统保存选择器。目标目录被移动后显示错误并清除失效配置，原有成品保留。
- 普通 APK、完整 APKS 和批量 ZIP 均已导出至默认目录，全部 APK 的 SHA-256 与原包一致，ZIP CRC 正常。
- 已目视检查浅色、深色、小屏、200% 系统字体与横屏设置布局。
- 主色 `#C29E64`，强调色 `#4C7543`；深色模式使用更亮的绿色以保持文字对比。
- 界面图标为固定来源的 Lucide 开源矢量，许可随源码和 APK 提供；APP 图标保留上传原图，标准缩放生成 Android 资源。
- 无网络或存储管理权限，无后台服务，禁用备份。导出不生成中间安装包，原有取消、失败和启动清理机制保留。

本轮没有 Android 8.0 真机验证；API 26–28 的目录授权检查使用兼容分支，已通过静态兼容性检查。测试使用专用无代码应用，没有操作物理手机。

构建与运行记录在本机 `.test-data/`，产物摘要在 `dist/verification-1.1.0.json`。
